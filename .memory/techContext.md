# Technical Context — Landing Page Baitani

## Framework & Dependencies
- Next.js 16.3.6 (App Router + Turbopack)
- React 19 + TypeScript
- Tailwind CSS v4
- Lucide React Icons
- Google Fonts (`Cinzel` & `Plus_Jakarta_Sans` via `next/font/google`)

## Run & Build Commands
- Development: `npm run dev`
- Production Build: `npm run build`
- Production Server: `npx next start -p 3005`
