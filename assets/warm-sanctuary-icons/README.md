# Warm Sanctuary icon set

16 original 24×24 SVG outline icons for proposed website navigation at Gereja Baptis Indonesia Baitani, Sukabumi. Concept set for church review; not an official identity asset or sign-off.

## Usage
Use the files from `icons/` as inline SVG to inherit `currentColor`. All paths use `fill="none"`, `stroke="currentColor"`, stroke 1.75, rounded caps and joins. Example: set `color: #1B1C1A` or `color: #785600` on the parent element. Do not treat these symbols as statements that a specific facility or ministry exists.

## Review and verification
`contact-sheet.svg` is a labeled, scalable review page; `contact-sheet.png` is its image preview. `size-theme-validation.png` shows all 16 icons at exactly 20, 24, 32 CSS pixels on #FBF9F6 and #1B1C1A backgrounds, with strokes adapted for contrast. 96 raster renders were produced successfully with CairoSVG; basic XML parsing and nonempty bitmap checks passed. This is a render validation, not an accessibility usability study or confirmation by the church. No website files changed.
